The identity is a **concentric target** — rings closing on a centre, the way
evidence resolves to a finding. It exists as a mark, a wordmark, and a lockup of
the two. That is the whole kit; there is no icon library to match and no
secondary logo.

Reach for the **lockup** by default. Drop to the **mark** when space is tight
or the context already says "WGO". Set the **wordmark** in running text only
when neither of those fits.
