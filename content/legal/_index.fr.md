WGO (Whats.Going.On.) est un projet à code ouvert. L'outil d'audit s'exécute sur
votre propre poste, dans votre propre compte d'IA — votre code, vos preuves et
vos constats ne touchent jamais ce site Web ni aucun serveur que nous exploitons.

Ces avis portent sur le site Web de présentation que vous lisez en ce moment : le
peu qu'il recueille, les conditions de son utilisation, et comment signaler un
problème.
