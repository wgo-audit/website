Two families, cleanly split. **Inter** carries the interface and the prose.
**JetBrains Mono** appears wherever exactness matters — install commands, file
paths, and the evidence a finding cites. The two are never mixed for effect.

Both ship as variable `.woff2` files in the repository, so the brand renders the
same offline, on a locked-down network, or ten years from now.
